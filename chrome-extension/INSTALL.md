# Инструкция по установке

## Шаг 1: Конвертация иконок (важно!)

Chrome не поддерживает SVG иконки напрямую. Нужно конвертировать SVG файлы в PNG:

### Вариант 1: Онлайн-конвертер
1. Откройте https://cloudconvert.com/svg-to-png
2. Загрузите `icon16.svg`, `icon48.svg`, `icon128.svg`
3. Конвертируйте каждый файл
4. Сохраните как `icon16.png`, `icon48.png`, `icon128.png` в папку `chrome-extension`

### Вариант 2: Использовать готовые иконки
Можете создать простые PNG иконки в любом графическом редакторе:
- 16x16 пикселей
- 48x48 пикселей
- 128x128 пикселей

## Шаг 2: Установка расширения в Chrome

1. Откройте Chrome
2. Введите в адресной строке: `chrome://extensions/`
3. Включите "Режим разработчика" (Developer mode) справа вверху
4. Нажмите "Загрузить распакованное расширение" (Load unpacked)
5. Выберите папку `chrome-extension`
6. Расширение установлено!

## Шаг 3: Настройка n8n

1. Откройте n8n
2. Создайте новый workflow
3. Добавьте узел "Webhook"
   - HTTP Method: POST
   - Path: `/add-word` (или любой другой)
4. Активируйте workflow
5. Скопируйте Production URL webhook

## Шаг 4: Настройка расширения

1. Нажмите на иконку расширения в Chrome
2. Вставьте скопированный URL в поле
3. Нажмите "Сохранить"

## Использование

1. Выделите слово на любой странице
2. Правая кнопка мыши
3. "Добавить [слово] в словарь"

Готово! 🎉
